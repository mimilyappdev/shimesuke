HOW TO USE
----------------------------------------------------------------

SchedulEX runs in your browser — no installation required.
Just open the HTML file in your browser and you're ready to go.
All data is stored locally on your device (browser localStorage).
Data is saved per device and does not sync automatically.

■ Getting Started

Open "SchedulEX_EN.html" in your browser (Chrome / Safari / Edge, etc.).
You can add it to your home screen to use it like a native app.

iPhone: Open in Safari → Share → Add to Home Screen
Android: Browser menu → Install App or Add to Home Screen

■ Adding a Desktop Icon (Windows)

Since this is a browser-based HTML file, no desktop icon is created
automatically. Follow these steps to create a shortcut with a proper
app icon (using the included "schedulex_icon.ico"):

1. Right-click "SchedulEX_EN.html" → "Send to" →
   "Desktop (create shortcut)"
2. Right-click the new shortcut on your desktop → "Properties"
3. Click "Change Icon..." and select the included "schedulex_icon.ico"
4. Click "OK" → "Apply" — the shortcut now shows the SchedulEX logo

■ Important: About Data Storage

App data is stored in your browser's localStorage.
Data may be lost in the following situations:
- Clearing browser cache or site data
- Removing the icon from your home screen
- Changing devices or resetting your device

It is strongly recommended to regularly back up your data via
Settings → Export Data (JSON).

■ Basic Usage

1. Add a project
   Tap "+ Add" and enter the project name, client name, deadline,
   and phase durations. The start date for each phase is automatically
   calculated backwards from the deadline.

2. Advance phases
   Tap the phase bar on a project card or update the phase from
   the project detail: Prep → Work → Final → Done.

3. Check the calendar
   The monthly calendar shows all project phase bars in color.
   Deadline dates are circled so you can see your workload at a glance.

4. Back up your data
   Go to Settings → Export Data to save a JSON backup file.
   When switching devices, use Settings → Import Data to restore.

■ Supported Environments

Latest versions of major modern browsers recommended:
Chrome / Safari / Edge.
Firefox and some specialized browsers may not function correctly.

■ Updates

If bug fixes or improvements are made, you can download the latest
version from your Booth download page.
However, free updates for future feature additions, spec changes,
or new products are not guaranteed.

----------------------------------------------------------------
MIGRATING FROM THE FREE VERSION
----------------------------------------------------------------

1. In the FREE version, go to Settings → Export Data to back up your data.
2. Open the downloaded PRO version HTML file in your browser.
3. If you had the FREE version added to your home screen, remove it
   and add the PRO version instead.
4. In the PRO version, go to Settings → Import Data to restore your backup.
