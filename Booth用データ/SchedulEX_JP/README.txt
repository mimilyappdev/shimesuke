【使い方】
----------------------------------------------------------------

〆スケはブラウザで動くアプリです。
HTMLファイルをブラウザで開くだけで使えます。インストール不要です。
データはすべてお使いのデバイス内（ブラウザのローカルストレージ）に保存されます。
データは端末ごとに保存され、自動同期されません。

■ 起動方法

ダウンロードした「SchedulEX_JP.html」をブラウザ（Chrome / Safari / Edge 等）
で開いてください。ホーム画面に追加するとアプリのように使えます。

iPhone：Safariで開いて「共有 → ホーム画面に追加」
Android：ブラウザメニューから「アプリをインストール」または「ホーム画面に追加」

■ パソコンのデスクトップにアイコンを置きたい場合

このHTMLファイルはブラウザで開く形式のため、自動ではデスクトップにアプリの
アイコンは作られません。以下の手順で、専用アイコン付きのショートカットを
作成できます（同梱の「schedulex_icon.ico」を使用します）。

1. 「SchedulEX_JP.html」を右クリック →「送る」→
   「デスクトップ（ショートカットを作成）」を選びます
2. デスクトップにできたショートカットを右クリック →「プロパティ」を開きます
3. 「アイコンの変更」ボタンを押し、同梱の「schedulex_icon.ico」を選択します
4. 「OK」→「適用」で、アイコンがSchedulEXのロゴに変わります

■ データの保存について（重要）

本アプリのデータはブラウザのローカルストレージに保存されます。
以下の操作でデータが消える場合があります：
・ブラウザのキャッシュ削除・サイトデータ削除
・ホーム画面からアイコンを削除
・機種変更・端末初期化

定期的に「設定 → データ書き出し」でJSONバックアップを取ることを
強くおすすめします。

■ 基本の使い方

1. 案件を追加する
   「＋ 追加」ボタンから案件名・クライアント名・納期・フェーズ日数を
   入力します。納期を入れると、各フェーズの開始日が自動で逆算されます。

2. フェーズを進める
   カードのフェーズバーをタップするか、案件詳細からフェーズを
   「準備中 → 作業中 → 仕上げ中 → 完了」と更新します。

3. カレンダーで確認する
   月表示のカレンダーに全案件のフェーズバーが色別で並びます。
   締め切り日は○で囲まれます。

4. データをバックアップする
   設定画面の「データ書き出し」からJSONファイルとして保存できます。
   機種変更のときは「データ読み込み」でインポートしてください。

■ 対応環境

Chrome / Safari / Edge 等の主要なモダンブラウザ最新版を推奨します。
Firefoxおよび一部特殊ブラウザでは正常に動作しない場合があります。

■ アップデートについて

不具合修正や機能改善を行った場合、Boothのダウンロードページから最新版を取得できます。
ただし、将来的な機能追加・仕様変更・新製品への無償アップデートを保証するものではありません。

【FREE版からの移行手順】
----------------------------------------------------------------

1. FREE版をお使いだった場合、先に「設定 → データ書き出し」でバックアップを取ります
2. ダウンロードしたPRO版HTMLファイルをブラウザで開きます
3. ホーム画面に追加していた場合はいったん削除し、PRO版を改めて追加します
4. PRO版で「設定 → データ読み込み」からバックアップを復元します
