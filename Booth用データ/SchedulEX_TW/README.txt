使用方式
----------------------------------------------------------------

SchedulEX 是在瀏覽器上運作的 App，不需要安裝。
只要用瀏覽器開啟 HTML 檔案，就能立即使用。
所有資料都儲存在您自己的裝置（瀏覽器的本機儲存空間）中。
資料是分別儲存在各個裝置上，不會自動同步。

■ 開始使用

請用瀏覽器（Chrome / Safari / Edge 等）開啟下載的「SchedulEX_TW.html」。
加入主畫面後，就能像 App 一樣使用。

iPhone：用 Safari 開啟 → 分享 → 加入主畫面
Android：瀏覽器選單 → 安裝應用程式 或 加到主畫面

■ 在電腦桌面建立圖示

本檔案是用瀏覽器開啟的 HTML 格式，不會自動在桌面建立圖示。
可依照以下步驟，使用隨附的「schedulex_icon.ico」建立專用圖示的捷徑。

1. 在「SchedulEX_TW.html」上按右鍵 →「傳送到」→
   選擇「桌面（建立捷徑）」
2. 在桌面上的捷徑按右鍵 → 開啟「內容」
3. 按「變更圖示」，選擇隨附的「schedulex_icon.ico」
4. 按「確定」→「套用」，圖示就會變成 SchedulEX 的標誌

■ 關於資料儲存（重要）

App 的資料儲存在瀏覽器的本機儲存空間中。
以下情況可能會導致資料消失：
・清除瀏覽器資料（快取、網站資料等）
・從主畫面移除圖示
・更換裝置或將裝置重設

建議定期從 設定 → 匯出為 JSON 進行備份。

■ 基本操作

1. 新增案件
   按「＋ 新增」，輸入案件名稱、委託人、交期與各階段天數。
   輸入交期後，會自動逆推算出各階段的開始日期。

2. 推進階段
   點選卡片上的進度條，或在案件詳細中更新階段。
   依照 準備中 → 製作中 → 收尾中 → 已完成 的順序進行。

3. 查看行事曆
   月行事曆會用不同顏色顯示所有案件的進度條。
   截稿日會有標記，工作量一目了然。

4. 備份資料
   從 設定 → 匯出為 JSON 可以儲存 JSON 檔案。
   更換裝置時，請從 設定 → 從 JSON 還原 來還原資料。

■ 支援環境

建議使用 Chrome / Safari / Edge 等主流瀏覽器的最新版本。
Firefox 及部分特殊瀏覽器可能無法正常運作。

■ 關於更新

修正錯誤或改善功能時，可從 Booth 的下載頁面取得最新版本。
但不保證未來的功能新增、規格變更或新產品會提供免費更新。

從免費版轉移
----------------------------------------------------------------

1. 在免費版中，從 設定 → 匯出為 JSON 儲存備份。
2. 用瀏覽器開啟下載的 PRO 版 HTML 檔案。
3. 若曾將免費版加入主畫面，請刪除後再加入 PRO 版。
4. 在 PRO 版中，從 設定 → 從 JSON 還原 還原備份。
