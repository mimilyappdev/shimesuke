SchedulEX (시메스케) PRO - 사용 방법 및 면책 사항
================================================================

SchedulEX (시메스케) PRO를 구매해 주셔서 감사합니다!
사용 전에 반드시 읽어 주세요.

----------------------------------------------------------------
사용 방법
----------------------------------------------------------------

SchedulEX는 브라우저에서 동작하는 앱입니다.
설치 불필요합니다.
HTML 파일을 브라우저에서 열기만 하면 바로 사용할 수 있습니다.
데이터는 모두 내 기기(브라우저 로컬 스토리지)에 저장됩니다.
데이터는 기기별로 저장되며 자동으로 동기화되지 않습니다.

■ 시작 방법

다운로드한 "SchedulEX_KR.html"을 브라우저(Chrome / Safari / Edge 등)에서 열어 주세요.
홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

iPhone: Safari에서 열기 → 공유 → 홈 화면에 추가
Android: 브라우저 메뉴 → 앱 설치 또는 홈 화면에 추가

■ PC 바탕화면에 아이콘 만들기

이 파일은 브라우저에서 여는 HTML 형식이라 자동으로 바탕화면
아이콘이 생성되지 않습니다. 아래 순서로 동봉된 "schedulex_icon.ico"를
사용해 전용 아이콘 바로가기를 만들 수 있습니다.

1. "SchedulEX_KR.html"을 마우스 오른쪽 클릭 → "보내기" →
   "바탕 화면에 바로 가기 만들기"를 선택합니다
2. 바탕화면에 생긴 바로가기를 마우스 오른쪽 클릭 → "속성"을 엽니다
3. "아이콘 변경" 버튼을 누르고 동봉된 "schedulex_icon.ico"를 선택합니다
4. "확인" → "적용"을 누르면 아이콘이 SchedulEX 로고로 바뀝니다

■ 데이터 저장에 대해 (중요)

앱 데이터는 브라우저의 로컬 스토리지에 저장됩니다.
다음과 같은 상황에서 데이터가 사라질 수 있습니다.
・브라우저 캐시 또는 사이트 데이터 삭제
・홈 화면에서 아이콘 제거
・기기 변경 또는 기기 초기화

설정 → 데이터 내보내기(JSON)로 정기적인 백업을 강력히 권장합니다.

■ 기본 사용법

1. 작업 추가하기
   "+ 추가" 버튼을 눌러 작업명·클라이언트명·마감일·단계별 일수를 입력합니다.
   마감일을 입력하면 각 단계의 시작일이 자동으로 역산됩니다.

2. 단계 진행하기
   카드의 단계 바를 탭하거나 작업 상세에서 단계를 업데이트합니다.
   준비 → 작업 중 → 마무리 → 완료 순으로 진행합니다.

3. 캘린더 확인하기
   월별 캘린더에 모든 작업의 단계 바가 색상별로 표시됩니다.
   마감일에는 표시가 생겨 작업량을 한눈에 파악할 수 있습니다.

4. 데이터 백업하기
   설정 → 데이터 내보내기로 JSON 파일을 저장할 수 있습니다.
   기기를 변경할 때는 설정 → 데이터 가져오기로 복원하세요.

■ 지원 환경

Chrome / Safari / Edge 등 주요 모던 브라우저 최신 버전을 권장합니다.
Firefox 및 일부 특수 브라우저에서는 정상 작동하지 않을 수 있습니다.

■ 업데이트에 대해

버그 수정이나 기능 개선 시 Booth 다운로드 페이지에서 최신 버전을 받을 수 있습니다.
단, 향후 기능 추가·사양 변경·신제품으로의 무상 업데이트는 보장하지 않습니다.

----------------------------------------------------------------
무료 버전에서 마이그레이션
----------------------------------------------------------------

1. 무료 버전에서 설정 → 데이터 내보내기로 백업을 저장합니다.
2. 다운로드한 PRO 버전 HTML 파일을 브라우저에서 열어 주세요.
3. 홈 화면에 무료 버전을 추가했다면 삭제하고 PRO 버전을 새로 추가합니다.
4. PRO 버전에서 설정 → 데이터 가져오기로 백업을 복원합니다.

----------------------------------------------------------------
향후 구독 플랜에 대해
----------------------------------------------------------------

향후 구독 플랜 제공을 예정하고 있습니다.
이 일회성 구매 버전의 데이터는 구독 플랜 출시 시에도
그대로 이어서 사용할 수 있습니다.

* 일회성 구매 버전은 계속 사용하실 수 있습니다.
  구독 플랜 출시 후에도 구매하신 라이선스가 만료되지 않습니다.
