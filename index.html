Problem

こんなこと、
ありませんか？

😰

「ラフ、いつまでだっけ？」

締め切りから逆算した工程が頭の中だけにある。いつの間にかラフが間に合わなくなっている。

🌀

複数案件で頭が混乱する

Aさんの修正中にBさんのラフが溜まる。どこから手をつければいいか分からなくなる。

🔥

締め切り前日に気づく

「あと1日しかない」と気づいてから焦る。余裕を持って進められているつもりだったのに。

How it works

3つの仕組みで、
納期を味方にする

Feature 01 — カレンダー

全案件が、
1枚のカレンダーに並ぶ。

月表示のカレンダーに各案件のフェーズバーが色別で表示されます。締め切り日は日付を○で囲んでひと目でわかるように。「今月どこが忙しいか」が俯瞰できます。

Feature 02 — 緊急度タブ

「あと〇日」が、
色で飛び込んでくる。

Feature 03 — 逆算スケジュール

納期を入れるだけで、
フェーズが自動で計算される。

ラフ・修正・清書それぞれに何日かけるかを設定しておくだけ。納期を入力すれば「今日ラフを始めないと間に合わない」が自動でわかります。設定は次回から自動で引き継がれます。
