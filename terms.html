Manual

使い方

〆スケはブラウザで動くPWAアプリです。インストール不要で、ホーム画面に追加するとアプリのように使えます。
データはすべてお使いのデバイス内に保存されます。データは端末ごとに保存され、自動同期されません。

基本の使い方

1

案件を追加する

右上の「＋」ボタンから案件名・クライアント名・納期・フェーズ日数を入力します。納期を入れると、ラフ・修正・清書の開始日が自動で逆算されます。

2

フェーズを進める

カードのフェーズバーをタップするか、案件詳細からフェーズを「ラフ中 → 修正中 → 清書中 → 完了」と更新します。完了にするとアクティブ枠が空きます。

3

カレンダーで確認する

月表示のカレンダーに全案件のフェーズバーが色別で並びます。締め切り日は○で囲まれるので、今月の忙しさが一目でわかります。

4

データをバックアップする

設定画面の「データ書き出し」からJSONファイルとして保存できます。機種変更のときは書き出したファイルを「データ読み込み」でインポートしてください。

💡 ホーム画面への追加
iPhone：Safariで開いて「共有 → ホーム画面に追加」
Android：ブラウザメニューから「アプリをインストール」または「ホーム画面に追加」
追加するとアプリのように起動できます。

対応環境

主要なモダンブラウザ（Chrome / Safari / Edge 等）の最新版での利用を推奨します。古いブラウザや一部の環境では正常に動作しない場合があります。

PRO / Subscription

有料プランについて

⭐ PRO版（買い切り）

PRO版はBoothにてHTMLファイルを販売しています。購入後、以下の手順でFREE版と差し替えてご利用ください。

⭐ PRO版への差し替え手順

  1. Boothにて購入し、HTMLファイルをダウンロードします
  2. FREE版で使っていた場合、先に設定 → データ書き出しでバックアップを取ります
  3. ダウンロードしたPRO版HTMLファイルをブラウザで開きます
  4. ホーム画面に追加していた場合はいったん削除し、PRO版を改めて追加します
  5. PRO版で設定 → データ読み込みからバックアップを復元します
PRO版のHTMLファイルはご自身のデバイスに保存してご利用ください。ファイルをサーバーに公開したり、第三者に配布することはご遠慮ください。

☁️ サブスクプラン

サブスクプランはGoogleアカウントでログインして利用するクラウド版です。データはサーバーに保存され、どの端末からでも同じデータにアクセスできます。

☁️ サブスクプランの特徴

  1. Googleアカウントでログインするだけで利用開始できます
  2. データはクラウドに自動保存されるため、バックアップ操作は不要です
  3. スマホ・PC・タブレットなどどの端末でも同じデータで利用できます
  4. 解約後もデータは一定期間保持されます（詳細は第7条参照）
カスタムスタンプ機能はPRO版（買い切り）専用です。サブスクプランには含まれません。
